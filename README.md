# Pengaruh Efikasi Diri Terhadap Tingkat Stres Periode UTS

Repositori ini berisi data dan analisis untuk proyek Data Science B28 yang meneliti hubungan antara efikasi diri dan tingkat stres mahasiswa selama periode UTS.

---

## Latar Belakang

Periode UTS sering kali menjadi salah satu sumber stres terbesar bagi mahasiswa. Penelitian ini ingin melihat apakah tingkat efikasi diri — yaitu seberapa yakin seseorang terhadap kemampuan dirinya — memiliki pengaruh terhadap tingkat stres mahasiswa saat menghadapi UTS.

## Rumusan Masalah

- Seberapa besar tingkat efikasi diri mahasiswa selama periode UTS?
- Seberapa tinggi tingkat stres yang dialami mahasiswa?
- Apakah efikasi diri berpengaruh signifikan terhadap tingkat stres?

## Metodologi

Data dikumpulkan melalui kuesioner yang disebarkan kepada mahasiswa selama periode UTS. Instrumen yang digunakan mengadaptasi:

- **General Self-Efficacy Scale (GSE)** untuk mengukur efikasi diri
- **Perceived Stress Scale (PSS)** untuk mengukur tingkat stres

Analisis dilakukan menggunakan Python dengan library:

- Pandas
- Numpy
- Matplotlib
- Scikit-learn
